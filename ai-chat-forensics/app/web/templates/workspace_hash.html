Workspace storage hash calculator

Recomputes VS Code's workspaceStorage/<hash> folder name from a folder path, so you can tie a session file back to the project folder it came from even without the original storage directory. Formula per workspaces.ts: md5(fsPath + ctime) for local folders (Linux uses the inode instead of ctime), md5(uri) for remote (WSL/SSH) folders. You supply the path and creation time/inode yourself - from a forensic image's timestamps, or a live (Get-Item $path).CreationTimeUtc - this tool never reads your filesystem.

Evidence: this formula reproduces the one documented worked example in notes.md (C:\dev\research + a known creation time → the real folder hash) exactly [observed]. Several variants are listed below because VS Code's exact path casing isn't always knowable in advance (drive letter case, for one) - check each against the real folder name you're trying to match.
